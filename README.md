# Поиск автомобилей по тексту, метаданным и цвету

Поиск по небольшому каталогу: TF-IDF для описаний, табличные признаки и RGB-гистограммы изображений. Сравниваются текстовый режим и объединение сигналов. Нейросетевые энкодеры не обучаются.

## Проверка

36 запросов к 12 автомобилям проверяют поиск другого ракурса известного объекта. В обоих режимах Recall@1 и MRR равны 1,0. Набор проверяет работу поиска внутри демонстрационного каталога и не показывает обобщение на новые автомобили или преимущество визуальных признаков.

## Запуск

```bash
pip install -r requirements.txt
python scripts/run_benchmark.py --config configs/demo_text.yaml
python scripts/run_benchmark.py --config configs/demo_hybrid.yaml
python scripts/serve_api.py
```

Конфигурации — `configs/`, код — `src/`, примеры и данные — в репозитории. Для содержательного сравнения нужны отдельные автомобили в test, визуально похожие отрицательные примеры и оценка каждого источника признаков по отдельности.
